# Отложенка (links-hold)

Небольшой Firefox-аддон: **копилка ссылок с группами**. Сохраняйте ссылки, не открывая их — откройте, когда понадобятся.

## Возможности

- 📥 Копилка ссылок: вставка пачкой или по одна, ссылки не загружаются, пока не открыты вручную
- 📁 Группы по смыслу («Почитать», «Скачать», …): создание, переименование, удаление (ссылки возвращаются во входящие)
- 🖱 Правый клик по любой ссылке → «Отложить в копилку» / в конкретную группу
- ▶ Открытие ссылки / ⤴ открытие всей группы пачкой (с интервалом)
- ➜ Перенос ссылок между группами, счётчик на иконке, галочка «Удалять после открытия»
- 📦 Экспорт/импорт групп в JSON

## Установка (подписанный xpi)

Firefox → меню ☰ → Дополнения и темы → ⚙ → «Установить дополнение из файла…» → выбрать xpi.

Для разработки: `about:debugging#/runtime/this-firefox` → «Load Temporary Add-on» → `manifest.json`.

## Сборка

Собрать zip/xpi (manifest.json должен быть в корне архива):

```powershell
Compress-Archive -Path .\* -DestinationPath .\links-hold.zip -Force
```

## Технологии

- Manifest V2 (Firefox 115+)
- Чистый JS без зависимостей: `storage.local`, `contextMenus`, `tabs`, `notifications`
